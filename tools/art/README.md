# tools/art — automated character-art pipeline

Prompts + scripts that turn text into game sprites. No dependencies: Node
built-ins, the global `WebSocket`/`fetch`, and the `agy` CLI.

| Piece | What it does |
|---|---|
| `tools/art/prompts.mjs` | Prompt data: `STYLES` (`2d` / `3d`), `CHARACTERS` (17 enemies + 4 heroes — outfit, props, mood and accent colour only; no real names, no reference/likeness wording) and `buildPrompt(style, ch)` |
| `tools/gen-art.mjs` | Runs one `agy` image-generation agent per character and collects the raw image into `art-src/` |
| `tools/chroma-key.mjs` | Removes the green background, trims, and writes the final sprite PNGs (+ a contact sheet) |

## Order

1. **Generate raw art**
   `node tools/gen-art.mjs [--style 2d|3d] [--only id1,id2] [--kind enemies|heroes] [--jobs 2] [--force]`
   (defaults: style `3d`, 2 agents in parallel). Characters that already have a
   file in `art-src/` are skipped unless `--force`. Every attempt is appended to
   `art-src/log.jsonl`.
2. **Look at the raw files** in `art-src/<kind>/`. Delete any you don't like and
   re-run `gen-art` for just those ids: `--only <id> --force`.
3. **Key + pack**
   `node tools/chroma-key.mjs [--only ids] [--size 384]`
   → enemies become `assets/enemies/<id>/walk.png`, heroes
   `assets/heroes/<id>/ready.png`, plus the contact sheet `art-src/sheet.png`
   (grid of the whole batch, handy for a final look).
4. **Refresh the manifest the game loads**
   `node tools/build-assets.mjs`

## Notes

- `art-src/` is raw generator output and **not committed** (it is git-ignored;
  see `.gitignore`). `log.jsonl` and `sheet.png` live there too.
- agy's image generator doesn't return the image in the stream; it saves it into
  its brain folder (`~/.gemini/antigravity-cli/brain/<conversation id>/`).
  `gen-art.mjs` reads the conversation id from the agent's NDJSON stream and
  copies the newest image out of that folder — so don't wipe the brain folder
  between steps.
- `chroma-key.mjs` looks for headless Chromium in
  `~/.cache/ms-playwright/chromium_headless_shell-*` (the Playwright browser
  cache — no npm install) and drives it over CDP for the canvas work.
- Only one pose per character is automated (`walk` for enemies, `ready` for
  heroes). The other poses (`kicked`, `idle`, `kick`, `cheer`, …) are still
  generated by hand per `docs/prompts/`.
- Tone rules: characters stay comic and harmless — cheeky, sneaky or sulky
  villains; cheerful, brave heroes; no weapons, nothing scary. Keep
  `prompts.mjs` in sync with the prompt docs when the roster changes.

## Manual generation (Google Flow / Gemini web)
Prompts in batches of 10: `docs/prompts/flow-batches.md`. Generate square images on the green
background, download them, and save each as `art-src/<kind>/<id>.png` (for example
`art-src/enemies/shohag.png`, `art-src/heroes/studentM.png`). Then run
`node tools/chroma-key.mjs && node tools/build-assets.mjs`. `gen-art.mjs` skips any id that
already has a file in `art-src/`.
